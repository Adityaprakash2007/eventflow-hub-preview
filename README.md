# EventFlow Hub — Preview

A standalone, self-contained preview build of the EventFlow Hub app (React + Vite + shadcn/ui).

Everything — JS, CSS, and images — is inlined into a single `preview.html` file, so it works completely offline with no server or backend required. Just open `preview.html` in any browser.

Note: since there's no live backend attached, data (events, registrations, payments) is simulated using mock data for demo purposes.
